# 儿童日常保健指南 — 设计文档

**日期：** 2026-05-09  
**目标受众：** 8岁男孩 + 父母（亲子共读）  
**输出形式：** 单个 HTML 文件（`children_health_guide.html`）

---

## 一、目标

创建一份亲子共读的日常保健指南，涵盖日常习惯、疾病预防、安全守则与每日打卡。语言活泼但内容专业，分层呈现（儿童层 + 父母贴士层）。

---

## 二、视觉风格

- **配色：** 绿色主调（`--guide-green: #0f6e56`），与现有 `tcm_medicine_guide.html` 一致
- **CSS 变量：** 沿用现有 `:root` 变量体系，便于主题统一
- **卡片风格：** 白底、细边框、圆角8px，父母贴士用琥珀色底条（`--guide-amber-bg`）
- **标签/按钮：** 圆角胶囊形，激活态绿色高亮

---

## 三、页面结构

```
Header（标题 + 副标题 + 简介）
Toolbar（粘性）
  ├── 搜索框（关键词过滤全页内容）
  ├── 主标签：日常习惯 / 预防疾病 / 安全守则 / 每日打卡
  └── 分类快速筛选（随标签切换）
Content Area
  └── 内容卡片网格（可展开 + 搜索高亮）
```

---

## 四、内容板块

### 标签一：日常习惯
分类：口腔卫生 / 饮食营养 / 运动睡眠 / 个人卫生 / 屏幕时间

| 卡片 | 标签 | 父母贴士 |
|------|------|---------|
| 每日刷牙（早晚各2分钟，含氟牙膏） | 口腔卫生 | 晚间刷牙后不再进食，减少蛀牙60% |
| 均衡饮食（五色蔬果，限糖零食） | 饮食营养 | 不强迫进食，建立固定餐点时间 |
| 足量饮水（每天6-8杯，首选白水） | 饮食营养 | 用有趣水杯增加喝水兴趣 |
| 规律睡眠（9-11小时，固定作息） | 运动睡眠 | 睡前1小时禁止所有屏幕 |
| 每日运动（60分钟中等强度户外） | 运动睡眠 | 课间跑跳也算入每日运动量 |
| 洗手习惯（7步洗手法，20秒以上） | 个人卫生 | 餐前便后、触碰宠物后必洗 |
| 屏幕时间（娱乐不超2小时/天） | 屏幕时间 | 学习用途不计入，设置专注时段 |

### 标签二：预防疾病
分类：增强免疫 / 感冒预防 / 季节注意 / 生病处理

| 卡片 | 标签 |
|------|------|
| 免疫三角（睡眠+营养+运动） | 增强免疫 |
| 感冒预防（不共餐具，及时增减衣物） | 感冒预防 |
| 咳嗽礼仪（肘部遮挡，不对人咳嗽） | 感冒预防 |
| 换季保暖（春秋早晚温差大，多带一件） | 季节注意 |
| 疫苗接种（按时接种，保管免疫记录） | 季节注意 |
| 发烧处理（38.5°以下物理降温；何时就医） | 生病处理 |

### 标签三：安全守则
分类：居家安全 / 交通安全 / 水上安全 / 网络安全

| 卡片 | 标签 |
|------|------|
| 用电安全（不湿手触插座，不乱拔插头） | 居家安全 |
| 防火防烫（不独自用热水壶，远离明火） | 居家安全 |
| 交通安全（过马路等信号灯，骑车戴头盔） | 交通安全 |
| 水上安全（不独自游泳，无监护不玩水） | 水上安全 |
| 网络安全（不与陌生人分享个人信息） | 网络安全 |
| 紧急联系（记住110/120，记住家庭地址） | 居家安全 |

### 标签四：每日打卡
三段式 Checklist，勾选状态存入 `localStorage`，每天自动重置。

**早晨（6项）：** 喝温水、刷牙、洗脸、吃早饭、检查书包、道早安  
**白天（4项）：** 课间活动、饭前洗手、多喝水、午休  
**晚间（5项）：** 洗澡/洗手脸、刷牙、整理书包、阅读15分钟、按时上床

## 五、交互功能

| 功能 | 实现方式 |
|------|---------|
| 关键词搜索 | `input` 事件过滤卡片，高亮匹配文字 |
| 主标签切换 | JS 显示/隐藏对应区块 |
| 分类筛选 | 按 `data-cat` 属性过滤卡片 |
| 卡片展开 | 点击展开详细内容 + 父母贴士 |
| 每日打卡 | `localStorage` 存储，按日期自动重置 |
| 清除搜索 | 重置所有过滤状态 |
