# 武汉生活成本认知指南 — 设计文档

**日期：** 2026-05-09  
**目标受众：** 8岁武汉男孩 + 父母（亲子共读）  
**输出形式：** 单个 HTML 文件（`wuhan_life_cost_guide.html`）

---

## 一、目标

创建一份面向8岁男孩的生活成本认知指南，帮助孩子建立金钱与劳动价值观。
以武汉2024-2025年真实数据为基础，用「热干面（10元/碗）」作为统一参考单位，
让抽象的数字变得直观可感。语言活泼轻松，父母贴士层提供更多背景。

---

## 二、视觉风格

- **配色：** 绿色主调（`--guide-green: #0f6e56`），与现有指南一致
- **CSS 变量：** 沿用 `:root` 变量体系（`--guide-*`）
- **卡片风格：** 白底、细边框、圆角8px
- **父母贴士：** 琥珀色底条（`--guide-amber-bg`）
- **热干面单位：** 每个价格旁配 🍜×N 标注（绿色胶囊样式）
- **标签/按钮：** 圆角胶囊形，激活态绿色高亮

---

## 三、页面结构

```
Header（标题 + 副标题 + 说明 + 热干面汇率说明）
Toolbar（粘性）
  ├── 搜索框（关键词过滤全页内容）
  ├── 主标签：一天花多少 / 一个月账单 / 一年大数字 / 普通人怎么挣 / 妈妈的付出
  └── 分类快速筛选（随标签切换）
Content Area
  └── 内容卡片网格（可展开 + 搜索高亮 + 碗数换算）
互动计算器（"需要工作多久"）
```

## 五、互动计算器

**"需要工作多久？"计算器**

- 左侧：选择职业（外卖员 / 网约车 / 快递员 / 工厂工人）
- 右侧：选择商品（一碗热干面 / 一件衣服50元 / 玩具100元 / 一个月房租3000元 / 一辆自行车600元 / 一台iPad5000元）
- 结果：显示需要工作多少小时/分钟，以及🍜碗数

## 六、交互功能

| 功能 | 实现方式 |
|------|---------|
| 关键词搜索 | `input` 事件 + debounce 过滤卡片，高亮匹配文字（全局正则） |
| 主标签切换 | JS 显示/隐藏对应区块 |
| 分类筛选 | 按 `data-cat` 属性 + 事件委托 |
| 卡片展开 | 点击展开详细内容 + 父母贴士（`button` 元素，支持键盘） |
| 搜索高亮 | 全局正则替换 + `escHtml` 安全处理 |
| 清除搜索 | 重置所有过滤状态 |
| 计算器 | 纯JS，下拉选择即时计算 |
