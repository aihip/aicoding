### Section A：6大核心能力

每张能力卡片包含：
- 图标emoji + 能力名称 + 一句话定义
- 为什么8岁要练（大脑发育背景）
- 具体练法（3–5条，可直接执行的活动）
- 每周建议时长
- 父母小贴士

**能力一：🧠 专注力**
- 定义：持续专心做一件事的能力
- 为什么练：8岁大脑前额叶皮质正在发育，是训练专注力的窗口期
- 怎么练：
  - 番茄钟学习（25分钟专注 + 5分钟休息）
  - 积木/拼图/乐高（无干扰专注构建）
  - 棋类游戏（围棋/象棋，每周2次，每次30分钟）
  - 学习时手机放门外，电视关掉
  - 每天固定时间段做作业（形成仪式感）
- 建议时长：每天至少1次持续专注≥25分钟
- 父母提示：不要在孩子专注时打扰，哪怕是送水果。等他停下来再说。

**能力二：💪 体能与运动**
- 定义：身体协调、力量、耐力与运动技能
- 为什么练：运动直接促进大脑海马体发育，提升记忆力和情绪
- 怎么练：
  - 跑步（每天20分钟以上，心率≥120次/分钟）
  - 跳绳（每天100–300个，提升协调性）
  - 游泳（每周1–2次，全身运动）
  - 球类（足球/篮球/羽毛球，团队协作+手眼协调）
  - 户外自由玩耍（爬树、跑跳，每天≥30分钟）
- 建议时长：每天累计60分钟中等强度运动（WHO标准）
- 父母提示：减少接送，多让孩子走路或骑车。路程就是运动机会。

**能力三：📖 阅读与表达**
- 定义：理解文字、语言表达、逻辑叙述的能力
- 为什么练：8岁是阅读爆发期，词汇量和阅读速度快速增长
- 怎么练：
  - 每天自主阅读20–30分钟（纸质书，非屏幕）
  - 睡前亲子阅读10–15分钟（父母朗读或共读）
  - 每周写一篇日记（3–5句话即可）
  - 饭桌上说今天最有趣的事（锻炼语言组织）
  - 讲故事给爸妈听（复述所读内容）
- 建议时长：每天30–40分钟阅读
- 父母提示：允许孩子读漫画、科普读物，不限制"只能读名著"。让阅读先变成乐趣。

**能力四：🎨 创造力与想象力**
- 定义：用新方式解决问题、自由想象和创作的能力
- 为什么练：创造力不是天生的，8岁正是通过"玩"来激活右脑的关键期
- 怎么练：
  - 画画（不评判好不好看，让孩子自由画）
  - 搭建（积木、废纸箱做模型）
  - 角色扮演游戏（自编故事当导演）
  - 手工（折纸、剪贴、做贺卡）
  - 音乐（哪怕只是随意敲打、哼唱）
- 建议时长：每天30分钟自由创作时间
- 父母提示：不要说"这画的什么呀"。说"给我讲讲这幅画的故事"。

**能力五：🤝 社交与情绪管理**
- 定义：与他人相处、理解情绪、处理冲突的能力
- 为什么练：8岁开始进入"同伴关系"敏感期，友谊对心理健康至关重要
- 怎么练：
  - 每周和同学/朋友玩耍≥1次（非屏幕）
  - 教孩子表达情绪：用"我感到…"句式
  - 当孩子生气时，引导他说出感受而非爆发
  - 让孩子参与家庭决策（今天吃什么？周末去哪？）
  - 鼓励孩子主动帮助同学（培养利他心）
- 建议时长：每周至少2次社交活动（不含班级上课）
- 父母提示：不要替孩子解决所有冲突。让他先尝试，卡住了再帮。

**能力六：🏠 自理与责任感**
- 定义：照顾自己、完成任务、承担家庭责任的能力
- 为什么练：8岁已经完全有能力承担部分家务，自理能力直接影响自信心
- 怎么练：
  - 每天自己整理书包、房间
  - 固定家务任务（倒垃圾/摆碗筷/扫地）
  - 自己设闹钟起床（不靠爸妈叫）
  - 管理自己的零花钱（记账）
  - 照顾植物/小动物（如果有的话）
- 建议时长：每天家务15–20分钟
- 父母提示：让孩子做家务时，接受"做得不完美"。重点是参与，不是结果。

### Section C：睡眠计划

#### 为什么8岁要睡足觉
- 睡眠期间大脑"整理"白天学到的知识（记忆巩固）
- 生长激素90%在深度睡眠时分泌（身高发育）
- 睡眠不足导致：注意力下降、情绪暴躁、免疫力降低、肥胖风险增加

#### 科学数据
- WHO推荐：6–12岁儿童每天需要 **9–12小时** 睡眠
- 8岁黄金睡眠时长：**9–10小时**
- 最佳入睡时间：**晚上8:30–9:00**
- 最佳起床时间：**早上6:00–6:30**（如8:30入睡）

#### 理想作息时间表

| 时间 | 活动 | 说明 |
|---|---|---|
| 6:00 | 自然醒/闹钟 | 不要赖床，起床后喝温水 |
| 6:10 | 洗脸刷牙 | 7步洗脸程序，2分钟刷牙 |
| 6:30 | 早饭 | 热干面/粥/鸡蛋，不跳过 |
| 7:00 | 出发上学 | |
| 15:30–17:00 | 运动/玩耍 | 放学后先运动，再做作业 |
| 17:00–18:30 | 作业+阅读 | 番茄钟，每25分钟休息5分钟 |
| 18:30 | 晚饭 | 家人一起吃，不看手机 |
| 19:30 | 自由时间 | 画画/手工/游戏，无屏幕 |
| 20:30 | 开始睡前程序 | |
| 21:00 | 关灯上床 | 最晚9点躺下，保证9小时 |

#### 睡前5步程序（20:30–21:00）
1. 🛁 **洗澡/洗脚**（10分钟）— 体温升高后下降帮助入睡
2. 🦷 **刷牙**（2分钟）— 晚上刷牙比早上更重要
3. 📖 **亲子阅读**（10分钟）— 纸质书，昏黄灯光，不看手机
4. 🌙 **整理明天的书包**（3分钟）— 让大脑"结束"今天的任务
5. 💤 **关灯，深呼吸**（5分钟）— 腹式呼吸：吸4秒，屏2秒，呼6秒

#### 影响睡眠质量的坏习惯
- ❌ 睡前1小时看手机/平板（蓝光抑制褪黑素分泌）
- ❌ 睡前吃零食/喝饮料（血糖波动影响深度睡眠）
- ❌ 房间太亮/太热（理想睡眠温度：18–22°C，黑暗环境）
- ❌ 周末睡懒觉超过2小时（打乱生物钟）
- ❌ 带手机进卧室（深夜偷看）

#### 睡眠不足的可见危害（可视化呈现）
- 注意力下降40%（等于喝了2杯酒后的状态）
- 记忆力减退（昨天学的东西记不住）
- 身高发育减缓（生长激素减少）
- 情绪暴躁、爱哭、朋友关系变差
- 免疫力下降，更容易生病
